새 프로젝트를 인덱싱합니다. 아래 순서대로 진행하세요.

## 0단계: 프로젝트 루트 확인

이 skill 파일의 위치를 기준으로 프로젝트 루트를 파악하세요.
이 파일은 `{프로젝트루트}/.claude/skills/project-add/SKILL.md` 에 있으므로,
프로젝트 루트는 이 파일에서 3단계 상위 디렉토리입니다.

## 1단계: 정보 수집

사용자에게 다음 두 가지를 질문하세요:

1. **프로젝트 이름** (영문, 예: myapp, shopping)
2. **프로젝트 경로** (예: ~/AndroidStudioProjects/MyApp)

$ARGUMENTS 가 있으면 거기서 이름과 경로를 파싱하세요.
없으면 사용자에게 하나씩 물어보세요.

## 2단계: 인덱싱 실행

**반드시 당신(Claude)이 Bash 도구를 사용해서 아래 명령어를 직접 실행하세요.**
**절대로 사용자에게 명령어를 보여주고 직접 실행하라고 하지 마세요.**
**절대로 `!` 프리픽스 실행을 안내하지 마세요.**

Bash 도구 호출 시 timeout을 600000(10분)으로 설정하세요.
실행 전에 "인덱싱을 시작합니다. 프로젝트 규모에 따라 시간이 걸릴 수 있습니다." 라고 안내하세요.

실행할 명령어:
```
{프로젝트루트}/index.sh --name {프로젝트이름} "{프로젝트경로}"
```

## 3단계: 검색 커맨드 자동 생성

인덱싱이 완료되면, 아래 내용으로 검색 커맨드 파일을 생성하세요:

파일 경로: `{프로젝트루트}/.claude/skills/search-{프로젝트이름}/SKILL.md`

파일 내용:
```
---
name: search-{프로젝트이름}
description: {프로젝트이름} 프로젝트 코드베이스에서 관련 코드를 검색합니다
---

{프로젝트이름} 프로젝트에서 다음 내용을 검색해주세요: $ARGUMENTS

mcp__android-butler__search_android_code 도구를 사용하되, project 파라미터에 "{프로젝트이름}"을 지정하세요.
검색 결과를 바탕으로 질문에 대해 정리해서 답변해주세요.
```

## 4단계: 완료 안내

사용자에게 다음을 알려주세요:
- 인덱싱된 청크 수
- `/search-{프로젝트이름}` 커맨드가 생성되었다는 것
- 사용 예시: `/search-{프로젝트이름} 로그인 API`
