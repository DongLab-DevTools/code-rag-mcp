code-rag-mcp 플러그인의 초기 셋업을 실행합니다.

## 수행 내용

- Python 3.10+ 확인 (없으면 Homebrew로 자동 설치)
- venv 생성
- requirements.txt 기반 패키지 설치
- Jina 임베딩 모델 가중치(~3GB) HuggingFace 캐시에 다운로드

## 0단계: 플러그인 루트 확인

이 skill 파일의 위치를 기준으로 플러그인 루트를 파악하세요.
이 파일은 `{플러그인루트}/skills/init/SKILL.md` 에 있으므로,
플러그인 루트는 이 파일에서 2단계 상위 디렉토리입니다.

## 1단계: init.sh 실행

**반드시 당신(Claude)이 Bash 도구를 사용해서 아래 명령어를 직접 실행하세요.**
**절대로 사용자에게 명령어를 보여주고 직접 실행하라고 하지 마세요.**
**절대로 `!` 프리픽스 실행을 안내하지 마세요.**

Bash 도구 호출 시 timeout을 600000(10분)으로 설정하세요.
실행 전에 다음과 같이 안내하세요:

> 초기 셋업을 시작합니다. 최초 1회에 한해 Python 설치, 패키지 설치, 임베딩 모델 다운로드(~3GB)가 진행되므로 수 분이 소요될 수 있습니다.

실행할 명령어:
```
{플러그인루트}/init.sh
```
